parameters-reference
++++++++++

name : name of the task 
id : id (uuid4 hex) of the single task 
status* : status of the task
desc : description of the task
created_time : task creation timestamp
target_start_time: task suggested/expected start time
target_time : task target completion time
dead_time : final deadline of the task
elapsed_time* : total time spent from start of the task till now
active_time* : total time spent actively on the task from the start, excluding paused times
priority : priority of the task , in natural number
is_complete : task complete or not 
is_running* : task running?
